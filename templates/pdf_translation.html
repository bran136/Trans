部署与使用

连接独立部署的 Zotero PDF2zh 服务，填写内网地址与 DeepSeek API Key（可沿用在线翻译）。使用 pdf2zh_next 引擎，无需 Zotero 客户端。

任务串行执行，关闭页面后继续处理。结果可预览、下载、删除或按保留天数清理。

尽量保留原文排版；公式、表格及图中文字的处理取决于文档和上游引擎，请核对重要内容。

文件与隐私

原文 PDF 与 DeepSeek API Key 会发送至所配置的服务，待翻译文本由该服务提交至 DeepSeek。请使用可信服务，仅上传有权处理的文档。

已提交上游的任务暂不支持中途取消。删除仅清理 Trans 保存的原文与结果，并移除任务列表中的记录；上游副本需另行清理。

论文翻译

使用 DeepSeek 翻译中英文论文，尽量保留原文排版。可生成独立译文或左右对照 PDF，方便阅读与核对。

随时查看任务进度，预览、下载翻译结果。关闭页面后任务继续处理，历史文件支持手动删除或到期自动清理。

使用说明

需配置 Zotero PDF2zh 服务与 DeepSeek API Key。请使用可信服务，并仅上传有权处理的文档：原文与密钥将发送至该服务，待翻译文本会提交至 DeepSeek。

请核对译文中的重要内容及公式、图表。上游开始处理后暂不支持中途取消；删除任务仅清理 Trans 中的记录与文件，不影响上游副本。
